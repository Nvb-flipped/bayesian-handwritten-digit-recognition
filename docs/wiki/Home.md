# Bayesian digit recognition

CISC3024 Pattern Recognition — AI Assignment #2.

An executed last-layer Bayesian study motivated by [Laplace Redux (2021)](https://papers.nips.cc/paper/2021/hash/a7c9585703d275249f30a088cebba0ad-Abstract.html). This is a project adaptation, not the paper's benchmarks.

- [Reproduction](Reproduction.md)
- [AI workflow](AI-Workflow.md)

Laplace accuracy: 97.69% ± 0.16% across three initialization seeds on one test set. Probability scores are worse than MAP. The negative result is retained.
